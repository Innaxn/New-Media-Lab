# Glass house 



# Installation 

for material ui go to the client folder and do:
npm install @mui/material @emotion/react @emotion/styled
npm install @mui/icons-material

# How to run 

## Front-end 
```Bash 
    cd .\client\
    npm start
``` 

## Back-end 
```Bash
    cd .\server\
    . .venv\Scripts\activate
    python manage.py runserver
```
